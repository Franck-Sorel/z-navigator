# 09 — Monetization

Monetization is a later concern, but the *policy* must be locked in early to avoid a
conflict of interest.

## Realistic revenue paths

| Revenue path | When to use | Main risk |
|---|---|---|
| Affiliate / referral | Early consumer MVP | Bias / provider coverage |
| Premium alerts | After repeated usage | Low willingness to pay |
| Deadline planning | After route reliability data exists | Liability if phrased as a guarantee |
| B2B API | After routing engine matures | Integration and support burden |
| Corridor intelligence | Later | Data licensing / privacy |

## The conflict-of-interest rule

Affiliate economics create a real risk: **the route that pays the most commission may not
be the route that is best for the customer.**

- **Commercial compensation must never silently alter the route score.**
- Separate **ranking logic** from **monetization**.
- If commercial relationships exist, **disclose them**.

Monetization may make a route a *recommended partner* but must never reorder the neutral
ranking.
